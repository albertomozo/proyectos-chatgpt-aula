# Proyectos de aula con ChatGPT

Materiales para preparar un proyecto propio de ChatGPT, ejecutar una secuencia de prompts en chats separados y conservar documentos coherentes entre tareas.

**Empieza en [COMIENZA-AQUI.md](COMIENZA-AQUI.md).** El caso de ejemplo es INCIDENCIAS AULA: organizar un formulario y un registro de avisos. Los datos de partida son ficticios y no hay resultados o aprobaciones preexistentes.

## Dos modos

**Compacto, recomendado para empezar:** instrucciones en los ajustes y tres fuentes: índice, contexto y expediente con los documentos en secciones. La biblioteca y los prompts se consultan desde este repositorio, sin subirlos al proyecto.

**Estándar:** un archivo por documento producido, más contexto e índice. Facilita revisar archivos por separado, pero usa más fuentes. Consulta la guía antes de elegirlo.

## Una copia por alumno y por proyecto

Descarga el kit o el repositorio y crea un proyecto nuevo en tu cuenta de ChatGPT. Compartir el proyecto del docente sirve para una demostración o colaboración; no debe darse por hecha una función de duplicado completo. Si tienes cuenta de GitHub y el docente ha activado el repositorio como plantilla, puedes usar **Use this template** para generar tu repositorio propio. Si no, puedes descargar los materiales que el docente te facilite.

## Primera práctica

Ejecuta 00, 01, 02, 03 y 04. El resultado mínimo es contexto revisado, acta, revisión del acta, alcance y cronograma. Cada documento se conserva como borrador hasta que corresponda una decisión humana. Para ampliar: riesgos, auditoría y Kanban con 05, 06 y 07.

No necesitas Git, Python, una API ni automatizaciones para utilizar estos materiales. Construir el formulario es una actividad posterior a la instalación del sistema.
