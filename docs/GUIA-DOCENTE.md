# Preparación y distribución para el docente

## Qué se distribuye

El repositorio contiene un caso de inicio y una plantilla vacía. La vía principal es descargar un kit y crear un proyecto propio. Un proyecto compartido del docente puede mostrar el proceso; no es un mecanismo de clonado completo garantizado.

Los kits no contienen soluciones docentes ni documentos aprobados. El ejemplo de partida es nuevo y ficticio: no debe confundirse con versiones documentales previas de otro proyecto INCIDENCIAS AULA.

## Preparar la demostración

1. Crea en tu cuenta un proyecto llamado DEMO INCIDENCIAS AULA.
2. Utiliza el kit compacto del ejemplo, copia sus instrucciones y añade sus tres fuentes.
3. Ejecuta 00 y revisa contexto e índice. Define quién toma las decisiones de la actividad.
4. Ejecuta 01 y 02 para mostrar la diferencia entre redactar, revisar y aprobar.
5. Conserva una copia limpia del kit para que cada alumno empiece desde los mismos datos.

Si compartes la demostración, los miembros con acceso al chat pueden crear conversaciones en el espacio común: no es una vista de solo lectura estricta. No concedas edición cuando no sea necesaria. Cada alumno realiza la práctica en su proyecto propio para separar documentos y resultados.

La ayuda consultada indica hasta 10 colaboradores para proyectos de cuentas Plus y Go, 5 en Gratis y 100 en Pro; comprueba el límite de tu cuenta antes de compartir con toda la clase. Para grupos mayores, distribuye el kit mediante repositorio o aula virtual sin incorporar a todos al proyecto de demostración. [Fuente oficial](https://help.openai.com/en/articles/10169521-projects-in-chatgpt), consulta 23/11/2026.

Las cuentas Gratis tienen cuotas diarias de carga. Las tres fuentes iniciales ya pueden consumir las tres cargas del día; no prometas una práctica completa con cargas continuas. Comprueba cuotas antes de la clase y utiliza las opciones de fuentes disponibles, respetando sus límites, o distribuye la actividad en sesiones.

## Preparar el repositorio como plantilla

En GitHub, con permisos de administración, abre Settings y activa Template repository. Comprueba que aparece Use this template. El alumnado con acceso podrá generar otro repositorio con sus propios archivos; ese paso no crea un proyecto de ChatGPT.

Si el repositorio es privado, cada alumno necesita acceso para verlo o descargarlo. Puedes facilitar los ZIP mediante el aula virtual. Para acceso abierto por enlace utiliza una distribución pública autorizada. El alumno no necesita un repositorio propio para realizar la actividad en ChatGPT.

[Crear un repositorio plantilla](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-template-repository) y [crear uno desde ella](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-repository-from-a-template), consulta 23/11/2026.

## Secuencia de primera práctica

| Tramo | Actividad | Comprobación |
|---|---|---|
| Preparación | Descargar, crear proyecto, instrucciones y fuentes | Acceso a tres fuentes y caso correcto |
| Contexto | Prompt 00 y revisión de pendientes | CTX-00 e índice actualizados |
| Inicio | Prompts 01 y 02 | Acta y revisión sin aprobaciones inventadas |
| Planificación | Prompts 03 y 04 | Entregables relacionados con tareas |
| Ampliación | Prompts 05, 06 y 07 | Riesgos, auditoría y Kanban |

Ajusta el ritmo a tu grupo y a las cuotas de las cuentas. No es necesario completar los 16 prompts en una sola sesión. El formulario se construye cuando se concreten requisitos y herramientas; instalar el sistema no crea formularios ni tableros externos.

## Evidencias del alumno y nuevo proyecto

Solicita contexto, índice, expediente actualizado y un breve comentario de las correcciones que hizo el alumno a la IA. Revisa una relación ENT con TAR y una decisión con versión exacta. Su historial local debe permitir recuperar una versión anterior.

Comprueba que identifica pendientes, explica las dependencias y distingue propuestas de decisiones. Una prueba inventada se marca como simulada y no acredita el funcionamiento del formulario.

Para otro ejercicio reutiliza el kit vacío sin copiar aprobaciones. Conserva el catálogo de códigos. Si lo cambia, debe actualizar instrucciones, índice y referencias de los prompts de forma coherente.
