# Fuentes y límites comprobados

Fecha de consulta: 23/11/2026. Se consultaron páginas oficiales. Los pasos de la guía son una propuesta docente basada en funciones documentadas. La interfaz puede variar.

| Tema | Evidencia documental | Aplicación |
|---|---|---|
| Copia de proyecto | La ayuda describe compartir y copiar chats propios al salir; no garantiza clonar fuentes e instrucciones | Crear proyecto independiente desde el kit |
| Fuentes e instrucciones | Son partes diferenciadas del proyecto | Pegar instrucciones y añadir fuentes por separado |
| Guardar respuestas | Add to project sources permite reutilizar una respuesta | Registrar el título exacto de la fuente |
| Límite de archivos | Gratis 5; Go y Plus 25; Edu, Pro, Business y Enterprise 40 | Empezar con tres fuentes compactas |
| Ritmo de cargas | Gratis 3 cargas diarias en la ayuda consultada, sujetas a ajustes | No garantizar nuevas cargas durante toda la práctica; seguir avisos |
| Espacio compartido | Chat access permite interactuar y crear chats, sin edición de fuentes | Demostración y trabajo independiente |
| Plantilla GitHub | Permite generar otro repositorio con estructura y archivos | Alternativa al ZIP para alumnado con acceso |

## Referencias

1. [Proyectos en ChatGPT](https://help.openai.com/en/articles/10169521-projects-in-chatgpt).
2. [Uploading files and audio to ChatGPT](https://help.openai.com/en/articles/8555545-uploading-files-and-audio-to-chatgpt).
3. [Creating a repository from a template](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-repository-from-a-template).
4. [Creating a template repository](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-template-repository).

El ZIP contiene archivos, no una exportación importable de un proyecto de ChatGPT. El repositorio no se sincroniza automáticamente con las fuentes. Retirar una fuente antigua no borra su contenido en conversaciones previas; cada chat debe contrastar el índice vigente.
